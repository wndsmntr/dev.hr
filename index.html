Kriteria posisi

KriteriaTahun
Tahun = minimal pengalaman untuk kriteria itu. Isi 0 jika cukup disebut di CV.

Skor = 70% kriteria (tiap kriteria setara), 15% pengalaman, 15% pendidikan. Pengalaman dibaca dari angka “tahun/years” di CV, jadi tetap verifikasi manual.

Upload CV (PDF) Tarik file ke sini atau klik untuk memilih. Bisa banyak file sekaligus.
